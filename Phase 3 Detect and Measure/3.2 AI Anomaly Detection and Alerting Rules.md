

**Phase:** 3 - Detect and Measure  
**Framework Mapping:** NIST CSF 2.0 DE.AE-02, DE.AE-03 | NIST AI RMF (MEASURE 2.2, MEASURE 3.1)

## Purpose

To define actionable SIEM alerts that detect misuse, compromise, or anomalous behavior involving AI systems within NovaCloud Infrastrcuture

### **Alert 1: Automated Data Exfiltration via AI API**

- **Description:** Detects abnormally high volume of data being sent to external AI API, which could indicate a script looping through the codebase and exfiltrating it via prompt injection or compromised credentials.

- **Detection Logic:**
    
    - `IF` User/Service Account initiates > 100 API calls to DevMind.AI `WITHIN` 5 minutes.
        
    - `OR` Outbound input token count for a single user exceeds 500,000 tokens `WITHIN` 1 hour.
        
- **Action:** Generate `High` severity alert; temporarily suspend AI API access for that user ID.


### Alert 2: Secret / Credential Leakage Attempt

- **Description:** Detects if a developer accidentally attempts to send hardcoded secrets or infrastructure credentials in a prompt to an external LLM.
    
- **Log Source:** LLM API Gateway (Data Masking Layer).
    
- **Detection Logic:**
    
    - `IF` Outbound prompt payload matches regex patterns for AWS Access Keys (`AKIA...`), RSA Private Keys, or database connection strings.
        
- **Action:** Generate `Critical` severity alert; block the API call; trigger automated Slack message to the developer and Security Operations Center (SOC).


### Alert 3: Malicious Prompt Injection / Jailbreak

- **Description:** Detects attempts to manipulate internal AI agents (like a customer support chatbot or internal QA assistant) by feeding them malicious override commands.
    
- **Log Source:** Application Logs (User Inputs to AI).
    
- **Detection Logic:**
    
    - `IF` User input contains known jailbreak signatures (e.g., `"ignore all previous instructions"`, `"system override"`, `"you are now operating in developer mode"`).
        
- **Action:** Generate `Medium` severity alert; drop the prompt; log the source IP and user session ID.

### Alert 4: Shadow AI Usage (DLP Trigger)

- **Description:** Detects employees attempting to bypass the AI Acceptable Use Policy by using unauthorized public AI tools.
    
- **Log Source:** Endpoint DLP / Web Proxy.
    
- **Detection Logic:**
    
    - `IF` Paste event > 500 characters occurs `AND` Destination URL belongs to category `GenAI_Consumer` (e.g., ChatGPT, Claude, Perplexity).
        
- **Action:** Generate `Low` severity alert (educational); block the paste action; display AUP reminder popup on the endpoint.
