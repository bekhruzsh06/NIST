
**Phase:** 3 - Detect and Measure  
**Framework Mapping:** NIST CSF 2.0 ([DE.CM](https://de.cm/)-01, [DE.CM](https://de.cm/)-02) | NIST AI RMF (MEASURE 2.1)

## Purpose

To establish comprehensive visibility into how AI tools are interacting with NovaCloud's infrastructure. Traditional network logs do not capture the context of AI operations; therefore, specific AI telemetry must be aggregated into the central SIEM.

## 1. Critical Log Sources

All AI-related telemetry must be forwarded to NovaCloud's central SIEM (e.g., Datadog, Splunk) for correlation.

- **LLM API Gateway:** Captures all outbound requests to authorized third-party LLMs (e.g., [DevMind.AI](https://devmind.ai/)) and inbound responses

- **GitHub Enterprise Audit Logs:** Captures all read/clone events initiated by the AI Service Accounts. 

- **Endpoint DLP (Data Loss Prevention):** Captures unauthorized paste events into web-based Shadow AI applications (e.g., `chatgpt.com`).

## 2. Required Telemetry Data Points

For every authorized interaction with an AI agent, the following payload must be logged:

- **Timestamp:** UTC standard.
    
- **Identity:** The authenticated human developer ID _and_ the specific AI Service Account ID used.
    
- **Source/Destination:** Originating IP and the destination AI vendor endpoint.
    
- **Token Volume:** Input (prompt) token count and Output (completion) token count.
    
- **Payload Metadata:** A hash of the prompt and response (full text logging of prompts may violate privacy policies, so metadata and token counts are prioritized for anomaly detection).
    

## 3. Shadow AI Monitoring

- **DNS/Web Proxy Logging:** Monitor outbound DNS requests and web proxy logs for connections to known, unapproved AI domains.
    
- **Endpoint Agents:** Alert on high-volume copy/paste actions from the local IDE or database client to web browsers.
