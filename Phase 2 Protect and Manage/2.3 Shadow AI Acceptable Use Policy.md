
**Phase:** 2 - Protect and Manage  
**Framework Mapping:** NIST CSF 2.0 (GV.PO-01, [GV.AT](https://gv.at/)-02) | NIST AI RMF (GOVERN 1.2)

## 1. Approved AI Tools

Employees may only process company data using AI tools explicitly tested by the Security Team and listed in the internal NovaCloud App Directory. Currently approved tools operate under zero-retention contracts.

## 2. The "No Paste" Rule for Public LLMs

Employees are strictly prohibited from submitting, pasting, or uploading any of the following into public, unvetted AI tools (e.g., public web interfaces for ChatGPT, Claude, Gemini):

- Proprietary source code or algorithms 
- Customer data, PII or financial metrics
- Internal architectural diagrams or network topographies
- Passwords, API keys, or access tokens

## 3. Human-in-the-Loop (HITL) Accountability

AI tools are assistants, not autonomous workers.

- **Code Verification:** Developers are strictly responsible for the security and functionality of any code generated by an AI assistant.
    
- **Review Mandate:** All AI-assisted code must undergo standard human peer review and automated SAST testing before being merged into the main branch. Blindly committing AI-generated code without review is a violation of this policy.
    

## 4. Incident Reporting

If an employee suspects they have accidentally exposed sensitive company data to an unauthorized AI tool, they must immediately contact `security@novacloud.internal`. No punitive action will be taken for prompt, honest reporting of accidental exposure.
