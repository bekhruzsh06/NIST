## 3. Contextual Data Flow (The Incident Vector)

- **Input:** DevOps Engineer installed the DevMind.AI Github app via OAuth.

- **Access Level:** Granted `Read:All` to the entire private organization repositories

- **Data Transit:** Source code and secrets were transmitted over HTTPS to DevMind.AI servers

- **Processing/Storage:** DevMind AI used the payload for real-time autocompletion and persisted data into foundational model training pipeline (default setting for their Enterprise tier absent custom contract negotiation).
