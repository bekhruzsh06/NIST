# Phase 3: Detect and Measure

**Framework Mapping:** NIST CSF 2.0 (DE) | NIST AI RMF (MEASURE)

Traditional network logs often miss the context of AI operations. This phase defines how to capture AI telemetry and establishes alerting logic for AI-specific threats like prompt injection and automated data exfiltration.
