
# 🏢 Business Context: The NovaCloud Incident


## Company Overview

**NovaCloud** is a mid-sized B2B SaaS company providing time-tracking and resource allocation software for remote engineering teams

- **Size:** 150 employees (100% remote).
- **Infrastructure:** Cloud-native, hosted entirely on Amazon Web Services (AWS). 
- **Source Control:** GitHub Enterprise (Private Repositories). * 
- **Crown Jewels:** Proprietary scheduling algorithms, customer PII, and infrastructure as a code (IaC) scripts containing cloud credentials


## The Incident

Last week, a security researcher contacted NovaCloud's responsible disclosure email. The researcher discovered NovaCloud's proprietary scheduling algorithms and active AWS API keys being outputted by a popular, third-party Generative AI tool called **DevMind.AI**

**The Root Cause Investigation revealed:** 

1. A senior DevOps engineer, attempting to speed up development, integrated the DevMind.AI coding assistant directly into NovaCloud's primary private GitHub repository via API.

2. An AI agent was granted broad `Read` access to index the entire codebase to provide better code autocompletion

3. The codebase contained a legacy `.env` file with hardcoded AWS API keys that had not been rotated.

4. DevMind.AI's default enterprise tier allows the vendor to use customer prompts and ingested codebase data to fine-tune their foundational LLM. 

5. Because NovaCloud had no outbound data masking or semantic filtering, the proprietary code and secrets were ingested into DevMind.AI's training data and subsequently regurgitated to external users prompting the model.


## The Architecture of the Breach

-  **Internal Asset:** GitHub Enterprise (Private Repo: `novacloud-core`). 

- **Compromised Data:** `scheduling_engine.py` (Proprietary algorithm) and `legacy_prod.env` (AWS IAM Access Keys).

- **The Vector:** DevMind.AI REST API integration (Authorized by the engineer, unauthorized by IT/Security). 

- **The Failure Point:** Lack of AI vendor risk assessment, missing secret scanning in the CI/CD pipeline, and absence of an AI acceptable use policy. 

## Your Mission 

You have been brought in as the virtual Chief Information Security Officer (vCISO). The CEO has mandated a complete overhaul of how NovaCloud handles AI integrations. 

Using the **NIST CSF 2.0** and the **NIST AI RMF**, you must map the extent of the AI risk, design technical safeguards to prevent future data leakage, establish monitoring for AI anomalies, and draft an incident response playbook to handle rogue AI agents.
